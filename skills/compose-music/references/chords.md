# 三和弦、七和弦与转位

## 原理

三和弦（按三度叠置，根音—三音—五音）：

| 种类 | 半音结构 | 例（C 为根） |
|---|---|---|
| 大三 | 0-4-7 | C E G |
| 小三 | 0-3-7 | C Eb G |
| 减三 | 0-3-6 | C Eb Gb |
| 增三 | 0-4-8 | C E G# |

七和弦（在三和弦上加七音）：

| 种类 | 结构 | 例 |
|---|---|---|
| 大小七（属七） | 大三 + 小七 | C E G Bb |
| 小七 | 小三 + 小七 | C Eb G Bb |
| 减小七（半减） | 减三 + 小七 | C Eb Gb Bb |
| 减七 | 减三 + 减七 | C Eb Gb Bbb |

转位只改低音，不改根音、三音、五音、七音的称呼：

- 三和弦：原位 / 六和弦（三音在低）/ 四六和弦（五音在低）。
- 七和弦：原位 / 五六（三音在低）/ 三四（五音在低）/ 二和弦（七音在低）。
- 七和弦转位后七度变二度，所以转位名按“低音到二度”的度数叫。

等和弦：音响相同、写法与意义不同（如增三和弦转位后是另一个增三和弦）。

## 怎么做

- 写符号即可：`Cmaj7`、`Am7`、`G7`、`F#m7b5`、`Bb7`、`C/E`（斜线只管低音）。
- 别手算转位：`harmony.voice_lead()` 会自动选最近的声部排列，并避免声部交叉。
- 钢琴左手：根音（或五音）单独放低音；右手用三/四音密集或开放排列。
- 属七解决：三音（导音）上行半音到主音，七音下行级进到三音，根音跳四/五度到主音。
- 减七和弦有四种等和弦写法，可当“万能转调桥”，但别当稳定和弦用。

```sh
python3 scripts/harmony.py "C C/E C/G Cmaj7" --key C
```
