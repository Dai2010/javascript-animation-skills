# 和声进行与终止

## 原理

- 功能循环：`T → S → D → T`。最稳的骨架是 `I–IV–V–I`。
- 常见流行进行（大调）：
  - `I–V–vi–IV`（万能四和弦）
  - `vi–IV–I–V`
  - `I–vi–IV–V`（50 年代进行）
  - `IV–V–iii–vi`
  - 卡农：`I–V–vi–iii–IV–I–IV–V`
  - 华语 4536251：`IV–V–iii–vi–ii–V–I`
- 小调：`i–VI–III–VII`（自然小调循环）、`i–iv–V–i`（和声小调，更有解决感）。
- 终止：
  - 完全终止 `V–I`，旋律落主音
  - 半终止：停在 `V`
  - 阻碍终止 `V–vi`：该到 I 却拐去 vi，用来延长
  - 变格终止 `IV–I`：柔和、宗教感
- 借用与离调：`bVI`、`bVII`、`bIII`（同主音小调借用）；`V/V`、`V/ii`（副属，临时离调）。

## 怎么做

- 一句 4 小节：2 小节一个和弦或 1 小节一个和弦；每 4 小节必须出现一次 `V` 或 `IV–V`。
- 段落结尾用完全终止；段落中间用半终止，制造“还没说完”。
- 4 小节内别连续三个同功能和弦（I–vi–iii 会失去方向）。
- 想“高级”一点：把 I 换成 `Imaj7`、V 换成 `V7sus4 → V7`，或在副歌前加 `bVI–bVII`。
- 借用和弦放在终止前效果最好（`bVI–bVII–I`）。
- 每次换和弦都过一次 `voice_lead`，让共同音保留。

```sh
python3 scripts/harmony.py "IV V iii vi ii V I" --key C --roman   # 4536251
```
