# 转调与离调

## 原理

- **转调**：从一个调/调式换到另一个，新调得到巩固，通常发生在段落交界。
- **离调**：只借两三小节，很快回来，不巩固新调（副属和弦 `V/V` 就是最小离调）。
- 类别：
  - 近关系转调：两调调号相差一个升降号（C ↔ G、C ↔ F、C ↔ Am）
  - 远关系转调：相差两个以上升降号
  - 关系大小调转调：调号相同（C 大调 ↔ A 小调）
  - 同主音转调：主音相同、调式不同（C 大调 ↔ C 小调），永远是远关系
  - 同宫系统转调：五声调式里宫音不变、只换主音（C 宫 ↔ D 商）
- 手段：共同和弦（pivot）、属准备（新调的 V7）、突然对置。

## 怎么做

- 最稳的近关系转调：找两调共有的和弦当桥（C→G 用 `Am7` 或 `Em7`），下一小节给新调 `V7`。
- 同主音转调：直接把 I 换成 i，或先 `bVI–bVII` 铺垫。
- 五声/中国风：同宫系统换主音即可（宫→羽），不需要改调号。
- 副歌升 key：整段上移全音，最后一遍用，别在第一遍就用。
- 别在乐句中间硬转：转调点放在 4/8 小节边界。
- 代码：`chart` 里直接写新调和弦（`harmony.parse`），或在 `roman` 模式换 `key` 重开一段。

```sh
python3 scripts/harmony.py "Am7 D7 Gmaj7" --key G   # 借 A7? 检查 D7 的解决
```
