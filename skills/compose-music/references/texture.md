# 织体与声部

## 原理

- **柱式和弦**：一拍或半小节一次，和弦同时发声；气势、进行曲、民歌伴奏。
- **阿尔贝蒂低音**：低音—五音—三音—五音循环；古典钢琴常用。
- **分解和弦**：八分/十六分音符铺开，抒情、流行钢琴。
- **band 织体**：贝斯（根音+五音）+ 铺底（长音）+ 鼓（底鼓/军鼓/踩镲）。
- 四声部排列：密集（上方三声部在一个八度内）/ 开放（超过八度）。
- 旋律位置：最高声部是根音/三音/五音/七音，色彩不同（三音位置最“亮”）。

## 怎么做

- 低音区（<C3）不要放三度密集和弦，会糊；用根音八度、五度或开放排列。
- 左手根音与右手和弦分开音区，中间留出空隙。
- 旋律在最高声部时，内声部避开与旋律同度（除非要齐奏）。
- 织体跟着段落变：主歌分解、副歌柱式、桥段留白，比全曲一种织体更像成品。
- `compose.py` 的 `texture` 字段直接切换；`voices` 控制每和弦音数（3–5）。
- band 织体里贝斯走根音+五音最稳，别写旋律化贝斯（会与主旋律打架）。

```json
{"texture":"alberti","voices":4}
```
