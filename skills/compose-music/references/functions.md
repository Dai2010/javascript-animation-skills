# 调内和弦与功能

## 原理

自然大调各级三和弦：`I ii iii IV V vi vii°`（大 小 小 大 大 小 减）。
常用七和弦：`Imaj7 ii7 iii7 IVmaj7 V7 vi7 viiø7`。

和声小调：`i ii° III+ iv V VI vii°7`（V 是大三，vii°7 是减七）。

三种功能：

| 功能 | 和弦 | 作用 |
|---|---|---|
| 主 T | I（vi 可替代） | 稳定、落点 |
| 下属 S | IV（ii 可替代） | 推进、离开主 |
| 属 D | V（vii° 可替代） | 最强张力，必须解决到 T |

正三和弦 = I、IV、V（正音级 1、4、5 上）；其余为副三和弦，用来换色彩、做连接。

## 怎么做

- 进行走 `T → S → D → T`；`D → S`（V → IV）是逆行，只在装饰、延长时用。
- 想换色彩不改功能：`I → vi`、`IV → ii`、`V → vii°`。
- 属七解决（V7 → I）：七音下行级进、导音上行到主音、五音可到主音或三音、根音跳四度。
- 导七（vii°7）解决：导音上行到主音，其余音下行级进，常到 I 的重复根音。
- 小调里 `V` 必须是大三（升七级），否则没有导音、没有解决感。
- 检查平行五八度：相邻两个和弦的同两声部若都是纯五/纯八，判错。

```sh
python3 scripts/harmony.py "I vi IV V7 I" --key C --roman
```
