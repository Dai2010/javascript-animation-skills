# 节奏与节拍

## 原理

| 拍号 | 强弱 | 性格 |
|---|---|---|
| 2/4 | 强 弱 | 方整、进行曲 |
| 3/4 | 强 弱 弱 | 圆舞曲、流动 |
| 4/4 | 强 弱 次强 弱 | 最通用 |
| 6/8 | 强 弱 弱 次强 弱 弱 | 摇篮曲、船歌 |
| 5/4、7/8 | 由 2+3 或 3+2 组合决定 | 不规则 |

- 切分：音从弱位开始、延续到强位，强音被“搬”到前面；跨小节要写延音线。
- 连音：三连音 = 把二等分改成三等分（2 个八分 → 3 个）；五连音、七连音同理；二连音/四连音是把附点音符三等分改成二等/四等分。
- 弱起：从弱拍开始，第一小节不完整，结尾补足。
- 节奏型（rhythm pattern）比单个音更能决定风格。

## 怎么做

- 旋律强拍（1、3 拍）放和弦音或长音；弱拍放经过音、辅助音。
- 想要推动感：把重音从 1 挪到 2/4（雷鬼、流行反拍）。
- 切分写法：`{"bar":2,"beat":2.5,"dur":1.5}` —— 起于半拍、跨到下一拍。
- 三连音在 brief 里没有原生支持；要精确三连音就写 `beat` 为 1、1.333、1.667（`dur` 0.333）。
- 6/8 目前 `compose.py` 按四分音符数拍（`meter=6` 表示 6 个四分音符），要真正的 6/8 需按八分音符换算。
- 节奏别全用同一种时值：长—短—长、或附点+十六分的组合最容易“像旋律”。

```json
{"bar":3,"beat":2.5,"dur":1.5,"note":"C5"}
```
